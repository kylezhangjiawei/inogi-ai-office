### 修正与根因

1. 独立 BOM 编辑器：保存/删除使用同步请求标记防止连点重复提交；卸载后迟到响应不刷新、通知或关闭其他页面；用量限定正数、上限与四位小数；物料库加载失败时禁止保存并支持保留草稿重试。新增用例先复现 5 个失败，再修复为 BOM 页 13/13 通过。
2. 导航与工作台测试：修正缺失的 `subRoutePath` 依赖，并按实际已合并的内嵌详情、只读汇总与响应式驾驶舱验证交互，不恢复已淘汰页面。仓库/报价共 6 个原生按钮接回项目共用 Button，保留原行为和布局。
3. BOM 测试迁移：移除 16 项指向已不存在 `InventoryBomEditor` 的旧测试，独立 BOM 页面新增 10 项，原有 3 项保留。覆盖选中叶子 ID/版本/用量、冲突重试、物料库失败和丢失、重复提交、卸载与删除保护；原自由输入料号查分类逻辑已由正式物料 ID 选择替代。测试总数从 2479 变为 2473，不将数量减少隐瞒为同一批测试修复。
4. 发布模拟夹具：虚构数据目录移至项目 `.tmp/deploy-tests`，解决 Windows Bash 对系统临时目录祖先的权限问题；坏健康响应测试单跑通过（约 58 秒，三次模拟），并行时单次进程在 30 秒附近失败，将 Windows 测试进程上限改为 90 秒后全量通过。生产 `deploy.sh` 未改，模拟 API 健康等待仍为 1–2 秒，拒绝发布及失败快照断言保留；这是环境稳健性修正，不据此宣称生产部署成功。

## 本轮落地

| 链路 | 已实现的办理闭环 | 边界 |
|---|---|---|
| A：设备 / BOM → 计划 | 设备绑定产品根；发布不可变版本；新生产与整机备货计划引用版本；历史计划核对入口；停用保留快照 | 未核对不得扩大执行；原质检、退料等安全收尾不被阻断；不伪造历史 |
| B：库存 → 物料库 / 齐套 / 订单 | 统一只读分仓基础量；本地未覆盖发料、冻结、报废、盘亏只扣一次；正式计划另扣其他占用；保留来源时间 | 收货、良品退料、盘盈在 ERP 覆盖前不增加可用；缺同步/错单位/冲突为 null；真实零保留 0 |
| C：订单商品 → 正式物料 → 库存参考 | 正式编码与单位精确匹配；人工核对候选、依据、权限、审计、并发版本与重试；明确选择出货仓；来源变化失效 | 不按近似名称自动确认；不使用历史 stockQty；不构成预留或发货承诺；历史发票不重写 |
| C：旧库存入口收口 | 旧入库、出库、调整、AI 入库识别在控制器和服务入口返回 410；旧读接口需权限且读共享来源 | 未登录仍 401；未授权读取 403；停用路径不初始化、不查库、不清理历史 |

补充修正：重复发料冲突副本不再静默取第一条；备货核算的 null 不再显示为 0；导出携带待核对原因；正式齐套、普通齐套、物料详情展示逐仓来源时间。读取订单工作台不再自动写入默认设置或清理演示数据。
