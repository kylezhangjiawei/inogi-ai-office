# 前端拆分整理：研发共用模块

## 约束

保留页面、路由、权限、成员最近更新排序、接口载荷和视觉样式。仅整理前端；不改数据库和后端。当前工作区已有用户变更，基于当前内容迁移，不恢复旧版本，不提交或发布。

## 实施批次

1. 提取研发页面共用的类型、状态配置、任务树工具和成员显示组件到现有 `src/app/rd` 目录。
2. 提取任务操作对话框、移动目标树、评分卡、工作项和报告导出，详情页和工作台直接引用共用模块，不再依赖驾驶舱页面实现。
3. 删除确认无调用的四个旧组件：TaskCardUI、WorkspaceMoveDialog、SubsystemPanorama、旧 CreateTaskModal（保留在用 V2）。
4. 迁移现有测试的源码读取位置，补任务树/成员显示行为测试，执行前端类型检查、测试及构建，并检查真实页面。

## 验收

- 迁移的声明除 export 与导入位置外保持一致；不能用复制实现代替抽取。
- 新模块不能反向引用页面，保留现有业务动作和异常处理。
- 新测试先运行并确认能暴露未提供的新模块，然后迁移原有行为；已有测试保留断言。
- 报告真实检查结果，区分移动代码和实际删除的无调用代码。

## 执行说明

使用计划与验证方法记录边界；按用户已授权的当前工作区直接实施，不另建缺失未提交内容的工作树，不创建提交。重构不改变业务行为，因此以原实现等价迁移、行为回归和浏览器核查为主。
