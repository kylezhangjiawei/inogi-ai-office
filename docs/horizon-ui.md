# INOGI Horizon UI

本轮以 [Horizon UI](https://github.com/horizon-ui/horizon-tailwind-react-ts) 的浅色画布、白色卡片、深蓝标题和侧栏选中标记为参考，沿用项目已有 React / Tailwind / Radix 组件。

## 设计约定

面向内部办公人员，首页的首要任务是找到需要推进的事项。布局顺序为：欢迎与概览 → 待办和快捷操作 → 业务模块 → 状态分布与运行概况 → 最近动态。减少同一模块在首页重复出现。

| 用途 | 令牌 | 浅色值 |
| --- | --- | --- |
| 主操作、选中 | primary | #422AFB |
| 主要文字 | foreground | #1B2559 |
| 次要文字 | muted-foreground | #526080 |
| 页面画布 | background | #F4F7FE |
| 卡片 | card | #FFFFFF |
| 分隔线 | sidebar-border | #E9EDF7 |

- 保留现有 Google Sans / Noto Sans SC 字体栈；标题用 600–700 字重，正文用常规字重，数字用 tabular-nums，不增加网络字体依赖。
- 卡片圆角 24px，按钮及字段 12px，浮层内选项 8px。使用 Tailwind 默认圆角档位，旧 Material 形状令牌继续提供兼容。
- 阴影只区分普通表面和浮层，不以渐变、发光或动画作为交互提示。
- 红色和黄色保留给异常、优先级等真实业务语义。
- 键盘交互交给现有 Radix / cmdk；图标按钮提供名称，焦点清晰可见。

## 样式维护

`src/styles/theme.css` 定义主题与旧页面兼容规则，`materialTheme.ts` 同步 MUI。`--rdh-*`、`--hz-*` 引用共享主题；旧研发页面的 `--rd-*` 共用品牌色并保留现有浅色表面，避免其尚未适配暗色的控件产生低对比。页面保留自己的业务布局。

`src/styles/horizon.css` 提供公共 Horizon 表面、首页容器布局和窄屏壳层样式。新增功能应先使用语义令牌与公共组件，不复制硬编码主色或继续堆叠全局覆盖。

## 响应式与行为

- 桌面侧栏展开宽度 256px，大屏 280px；收起宽度 76px。
- 768–1023px 使用导航抽屉；由 Radix 管理焦点，跨入桌面宽度时关闭抽屉。
- 小于 768px 仍遵循项目原有规则，自动进入对应工作区的移动驾驶舱。此次不改变这条产品流程。
- 非研发页面的顶部搜索用于查找有权限且未隐藏的工作页面；研发驾驶舱保留任务搜索。
- 首页取数、权限、待办筛选、分页及跳转继续使用原有逻辑。
- 顶栏按自身可用宽度适配：中等窗口隐藏日期和账号副文案，保留搜索、语言、通知与头像；侧栏重新显示时会将当前页面定位到可见区域。
- 研发概览使用单一容器断点，统计跨列限定在现有网格内，避免窄屏产生隐式列。日报默认显示摘要，完整日报/月报按需展开；生成完成后同步摘要。
- 日常滚动保留导航，大屏由用户主动开启；“更多”菜单内可启用滚动自动收起。批量转派、人员管理和清空数据归入该菜单，沿用原权限及确认逻辑。
- 任务列数随实际内容宽度变化，单卡最小约 288px，最多 6 列；高度按主区域剩余空间计算，空间变化后补足任务分页。手机任务改为单列，较宽移动窗口采用两列。
- 弹窗默认保留视口安全边距并允许长内容滚动，关闭区域 40px；批量转派使用独立滚动正文与固定操作区，短窗口仍能访问确认、取消。
- 任务详情完整展示长标题，提交审核、审批和完成操作放在顶部。描述与主题按详情容器宽度分栏，事实摘要允许换行；人员筛选有可见说明与清除入口，并保留入口限定的人员范围。筛选不再隐藏已经打开的讨论窗口。
- 个人工作台在空间不足时按内容计算行高，辅助卡片完整参与布局；任务列表保持合理的滚动上限。筛选控件不被挤压，切换筛选会回到列表顶部。原生研发工作台将通知放在使用激励卡片前。
- 报价库保留全局单一标题，页内用紧凑说明与操作区；按内容纵向展开，指标按可用宽度切换两列或四列。商品与操作列固定，宽表内横向滚动；空状态独立居中。报价抽屉按自身宽度分列，阶梯价格输入保留字段标签，底部保存区固定可见。
