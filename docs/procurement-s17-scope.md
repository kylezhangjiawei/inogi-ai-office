# S17 第一批：供应商视角与物料核对

日期：2026-09-10。基于用户持续授权的采购模块改造，在现有供应商报价库中增量实现。

## 本批完成

- 在原 `/proc-quote-book` 页面增加“按物料比价 / 按供应商查看”，供应商视角可用 `?view=suppliers` 打开。
- 参考 S17 的左供应商、右信息与物料清单结构。桌面操作右置，窄屏上下排列；供应商每页 12 项，物料报价每页 10 项。
- 供应商搜索支持名称、当前档案 ID 和旧报价厂家名称；物料搜索支持 T+ 编码、ERP 编码、名称、规格、分类和厂家型号。物料筛选不会切换供应商。
- 展示真实档案来源、启停状态、已报价物料数量，以及物料编码、审核状态、单位、起订量、参考交期、币种、阶梯价、有效期。缺少数据时明确说明。
- 同名不同 ID 的供应商分别保留；无关联 ID 的报价逐条保留。档案缺失、冲突、停用分别显示。供应商 ID 是系统内档案关联，不等同 ERP 供应商编码；档案启用不代表供货资质通过。
- “查看全部厂家报价”按物料 ID 精确切换原比价表，自动展开全部厂家；“编辑报价”复用现有表单，传入原始物料与报价对象。切回供应商视角保留选择和筛选，刷新后处理选项移动、删除、分页缩减。
- 新增刷新、读取失败重试、空库查看物料入口。读取失败时隐藏旧供应商操作和旧统计，保留恢复能力。只读权限不展示编辑、导入按钮。
- 修正深链歧义：同名多规格物料不再静默选首条新增报价；明确物料 ID 才精确锁定，搜索深链解除旧 ID 范围。

## 数据实现

GET 报价库在原查询中附带物料现有 `tpInventoryCode / erpCode / reviewStatus`，以及真实关联供应商 `id / name / source / enabled`。仅附加只读字段，没有新增表、迁移或写接口；停用关联不被过滤，报价厂家名称快照与当前档案名称分开保留。

既有比价、阶梯 MOQ、参考交期、导入预览、报价编辑继续复用。本批没有重做报价库，也没有将报价关系提升为正式供货资格。
