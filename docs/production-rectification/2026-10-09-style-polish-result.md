# 生产与质量页面布局、按钮样式优化结果

日期：2026-10-09。结果：本地修改及本轮界面验收通过，未部署。保留原型页面分区与已有业务办理链。

## 已修问题

| 页面 / 场景 | 检查发现 | 本轮调整 |
|---|---|---|
| 生产、检验、不良、转产及质量弹窗 | 页面蓝色，操作弹窗、日历和下拉浮层变成紫色 | 增加局部生产质量主题；主操作、悬停、焦点、浮层统一蓝色，其他模块保持原主题 |
| 操作表单与确认弹窗 | 控件圆角、底部按钮尺寸不一致 | 统一边框、白色输入背景与圆角；表单底部按钮至少40px；手机常用按钮/选择器至少40px，说明图标和复选框不拉大 |
| P01 / P06 | 手机状态和操作位于表格右侧，无横滑提示，滚动后丢失任务标识 | 添加简短横滑提示，固定任务首列；双向滚动时表头保持上层 |
| P07 | 横滑后日期消失，底部“查看”点击区域仅22×28.5px | 固定日期列，保留选中底色；“查看”扩大为44×44px |
| P05 资料 / 独立验证 | “转量产必填（选填）”矛盾；复选框偏移到下一行 | 明确条件必填提示；复选框与说明同排顶对齐，可点击说明勾选；实际校验保持不变 |
| P05 长名称表单 | 选中长样品名称后撑宽手机弹窗 | 表单网格与字段容器允许收缩，不改变字段内容 |
| S10 收货 / QC | 手机上传附件入口距离表单约2610px | 唯一上传控件和本次附件列表移入当前表单；已保存历史证据仍在侧栏；上传/移除按钮不会误提交 |
| S11 退料 / S16 异常处置 | 退料操作与二次确认弹窗残留紫色 | 页面、办理和确认弹窗统一主题；通用操作弹窗按调用方传入主题，不将其他库存/ERP页面整体改色 |

## 验证结果

- 使用真实 React 组件、隔离 Chrome 和虚拟接口，检查1586×992、390×844；生产重点交互及表格补查320×844。
- 实查初始、悬停、键盘焦点、禁用、下拉、日历、长名称、草稿放弃、附件选择、横向/纵向滚动，以及原检验表单必填和错误提示。
- 浏览器检查未见页面脚本错误或页面级横向溢出。P03三次错误状态请求均被浏览器拦截后返回模拟错误；没有业务数据库或ERP写入。
- 生产入口/检验/异常/发货相关58项现有检查通过；分区检查另有计划41项、质量91项、生命周期25项通过（这些检查范围可能重叠，不相加为总数）。类型检查与前端构建通过。
- 桌面P01/P06/P07主表位置、尺寸与本轮修改前基线一致；没有推翻原型布局。

## 适配边界

320px窄屏仍保留业务宽表，需横滑查看其余列；在最右端操作时，P06部分状态列需略向左回滑阅读。任务标识、查看入口和点击操作均已验证，未压缩业务字段或缩小文字来强塞一屏。

本轮为界面与交互优化，不代表前序业务缺口已补齐。计划前置审批、最终闸门数据、全链路同步等既有缺口仍以[原整改结果第四节](./2026-10-09-prototype-implementation-result.md)为准。

采用技能：baseline-ui用于界面基线，ponytail用于最小正确修改，i-have-adhd用于沟通组织。未新增依赖，未部署。
