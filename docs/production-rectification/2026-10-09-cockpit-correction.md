# 生产驾驶舱 P00 对照整改

日期：2026-10-09。状态：本地代码已重构；未部署。仅本轮驾驶舱修正，不代表生产模块全部整改事项已经闭环。

## 方向纠正

用户指出上一版内容和布局偏离 P00；该反馈优先于此前“摘要条＋任务工作台”的设计建议。本轮以 P00 的蓝白驾驶舱为视觉依据，保留全局应用框架，重做内部页面结构。

- 顶部：生产驾驶舱标题、刷新与工作台入口，执行提醒，月份与发货概况。
- 指标区：整机计划、整机完工、计划剩余整机、今日在岗四张卡片，附可键盘访问的口径提示。
- 图表区：整机生产趋势、今日终检不良分布与一次合格率，桌面并排。
- 运营区：产线任务进度与待处理问题并排；型号／今日范围筛选、分页、风险原单处理、齐套查询仍可用。
- 历史发货保留折叠入口；报工和具体检验操作进入正式工作台办理。

## 原型内容与现有能力的取舍

| P00 内容 | 本轮处理 | 尚缺什么 |
| --- | --- | --- |
| 本月整机计划 | 正式月度计划整机目标合计 | 无 |
| 本月整机完工 | 保留卡片，显示“— / 等待最终闸门数据” | 性能检验与最终闸门结果关联生产单及数量 |
| 剩余整机／计划完成率 | 保留位置和明确的独立口径，不从普通终检推算 | 闸门合格数量归属本月计划 |
| 今日在岗 | 保留卡片并标注考勤待接入 | 实际考勤或签到来源，不能用获派人数替代 |
| 计划与完工趋势 | 当前展示真实报工柱形与累计首次终检合格曲线，标题和说明明确区分 | 闸门完工曲线、真实每日目标线；不按月目标均摊伪造计划线 |
| 今日不良分布 | 整机首次终检不良按检验工序分布，单位台 | 跨现场／过程检的唯一实物关联；本轮不拼接重复不良数 |
| 今日终检一次合格率 | 首次终检良品÷首次终检数量；无记录显示“—” | 无；复验不回写首次结果 |
| ECN 提醒 | 进入正式转产／ECN，待处理变更纳入协调表 | 不伪造“本期适用变更数” |
| 待出货 | 改为“距发货目标”：目标减本月实际净发货，最低零 | 原型中的数字并非可出货库存，避免误解 |

本月指选中月份。月度报工／终检按事件日期汇总全部授权任务，包含已结束的往月任务本月发生的记录；不从“跨月未完任务列表”倒推月度统计。今日质量明确使用上海实际日期，不跟随历史月份变为某个历史“今日”。型号筛选仅影响产线列表；风险筛选只影响风险区。
