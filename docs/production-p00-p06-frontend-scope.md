- 按工作日期展示各线组件/工序计划、报工、合格及返工待验数量；各工序独立展示。
- 在岗人数由管理层/厂长演示岗确认；0 人可作为明确确认，未确认显示暂缺。人数更正保留确认依据和历史。切换日期/岗位后旧输入不能误存到新上下文；未保存离开与刷新有保护。
- 质量与交付风险保留原期限和处理入口，未确认的停线不标为停线；已发布 ECN 有适用范围入口。

## P06
