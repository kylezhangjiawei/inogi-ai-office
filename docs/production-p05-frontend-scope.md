# P05 转产确认前端范围

入口：`/__preview/production-transfer`；查询参数 `transfer` 选择转产记录，`tab` 支持 documents / trials / problems / confirmations / history。

依据：V1.1 开发说明 P05（第 522–533 行）及 `高保真页面/生产/P05_转产确认与批次档案.png`。沿用 Horizon 界面，以样品结论、资料、试装、问题复验、岗位确认构成转产条件轨道。

## 已完成

- 三类样例：Q7 整机、FG 零部件、M2 电动执行器，按类型配置图纸 / BOM / SOP / SIP / ECN / 软件 / 硬件必需项和最低试装数量。FG 不要求软件、硬件、ECN，视频只对配置了要求的 M2 构成门槛。
- 资料版本摘要、补充资料及发布适用确认；资料变更生成新快照，历史试装保留，旧版岗位确认和问题复验不满足新版门槛。
- 试装日期、数量、结论、具体方法结果，最多 4 份本地图片或 MP4 视频证据；最新试装须达到最低数量并通过，不将多次小样本简单相加。未通过试装自动生成问题。
- 工艺登记整改，质量单独复验；复验失败退回整改。岗位确认须在资料、试装及问题验证完成后，由工艺、质量、生产负责人各自记录意见。
- 生产负责人仅在全部必需条件满足时提交转产确认；提交后锁定本批演示数据。记录导出包含版本、试装、问题、岗位意见和历史，并对 CSV 公式注入作转义。
- 搜索、状态过滤、批次与岗位切换；只读、空数据、读取失败与保存失败场景；未保存表单切换与离开保护、旧回调和对象错配防护、失败保留填写并可重试。
- 桌面为资料工作区加当前操作栏，窄屏使用单列及跳转到当前操作；键盘焦点可见，资料摘要与实际本地证据分别展示。

## 数据边界

这是本次浏览内的独立演示状态，刷新或重置恢复样例，不调用正式接口、不写浏览器持久化、不发送通知。岗位切换用于前端交互演示，正式权限需后续由服务端校验。原始图纸、BOM、SOP、SIP 和版本文件尚未接入，界面明确仅展示摘要；文件上传仅在内存读取，不能代替正式受控证据服务。

本页样品号和试产批次号为独立样例。档案入口明确标注“浏览批次档案演示”，不冒充当前批次原档案；尚无可核验的 S03 样品原单，因此不生成虚假的样品详情链接。提交不会创建正式 P09 档案、修改生产计划或触发放行、出货。
