V1.1 第一轮优化交付说明

2026-09-20 · 基于 原审核主报告 的 F01–F18 编号。本轮完成共享采购供给分配、人员筛选统计修正，以及重点工作区的列表、详情和导航整理。以下状态区分代码完成、验证完成与业务待补；原审核资料保留作为改造前的证据。

本轮交付范围

  • 管理与关键物料： 首页分开管理总览与个人内容；生产总览分开月度整体指标、现场作业和发货记录。关键物料分为全量目录、月度跟踪及详情，保留来源月份、产品、筛选和返回位置。
  • 采购与样品： 采购任务支持独立详情及“需求与资料、供应商报价、采购与到货、操作记录”四个栏目，沿用原办理动作。样品详情整理为“资料与验证、时间与采购登记、轮次与交付历史”三个栏目，保留图片、附件、测试草稿和离页保护。
  • 生产与仓库： 计划、批次、作业、检验以及转产、ECN、放行、发货、档案采用可筛选分页的列表和原记录详情，支持返回原范围。仓库分为“领料与签收”“入库、退料与盘点”两个视图及对应详情，保留授权办理和 ERP 核对边界。
  • 数量与视觉： 采购行→计划分配与仓库占用分别办理；共享供给未分配不计预计覆盖，来源变化后重新确认，保留释放与历史。修正小数差值和齐套取整边界。继续使用 Horizon 紫白系统、紧凑层级与内部滚动；保留既定页面命名、MateChat 弹窗与侧栏，以及个人采购工作台已确认的简化布局。
