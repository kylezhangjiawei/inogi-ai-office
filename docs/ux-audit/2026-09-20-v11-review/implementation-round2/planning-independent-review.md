# 规划与总览独立复核

复核范围：ProductionReadiness、PurchaseTiming/Delivery、ProductionScenario、ManagementRisk 及其正式页面读取边界。未操作浏览器，未写实际业务库。

已修复：

1. 已完成跨月计划会退出待办列表，但其本月首次终检仍应进入统计。管理统计改从完整正式计划记录取本月明确分类的终检；过程检、历史未分类、取消作业、其他产品与未来计划均不进入分母。
2. 齐套读取失败或空 BOM / 未知结果不能表现为暂无风险。增加待核对风险，读取失败的批次剩余量仍按已有真实合格完成计算。
3. 报工已满但终检/复验未完的逾期作业继续出现在作业风险。
4. 库存单位、同步、BOM 或待回写依据异常时，禁止新增正数库存占用；保留释放占用的能力。
5. 齐套复用统一仓库发料待回写工具，校验单位和数量，并去重相同发料事件。
6. 非有限/缺失/重复 BOM 编码与用量显式待核对；情景试算在读取供给前拒绝非法 BOM。
7. 复验回补不能超过原初检不良数，与生产执行汇总保持相同上限。
8. 已作废/取消订单不能因登记了日期而重新成为有效可用供给，原日期仍保留供核对。
9. 订单来源变更后重新确认供应商承诺，旧来源原承诺留在不可变历史，不能冒充新来源最初承诺。
10. 读取批次历史快照校验所属批次，拒绝用整月或另一批次范围读取同一快照。
