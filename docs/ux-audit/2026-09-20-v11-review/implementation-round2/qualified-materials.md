# F18：物料与供应商供货资格

已在正式报价库新增「供货资格」视图；供应商报价条目可定位到对应真实物料与供应商。物料详情通过按需展开的「供货资格」入口访问相同组件，避免增加默认详情密度。列表使用系统 Table、搜索、状态筛选和每页 12 条分页；查看关系时转入独立详情区域，再展开版本历史与证据。

## 已完成

- 以正式物料 ID × 供应商 ID 唯一登记，报价自由名称不能代替供应商档案。现有报价、供应商启用、单次样品通过均不会自动生成合格资格。
- 新关系必须先待审核；具有 `material:review` 的人员才能确认可供货、暂停或撤销。`quote-book:manage` 可登记和补充待审核关系，不能改写已确认关系。读取要求物料库或报价库页面权限。
- 每次确认记录适用产品、生效及失效日期、具体原因、操作人和审核证据。产品 ID 来自系统产品目录，证据从真实 FileAsset 读取；新文件要求本人上传，审核人可复用当前关系历史留存的证据。
- 可供货必须有有效证据；过期、尚未生效、物料审核撤回、供应商停用均显示准确状态。即使旧证据已删除，仍允许审核人暂停/撤销关系并保留历史；旧文件不再生成预览链接。
- 使用现有 RuntimeState 保存版本，不要求数据库迁移；串行化事务、版本比较和提交号幂等防止重复提交与过期覆盖。撤销后必须先重新登记待审。
