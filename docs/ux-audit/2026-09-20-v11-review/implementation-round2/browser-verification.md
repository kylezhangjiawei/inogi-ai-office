## 发现、修复与复验

<!-- FINAL_BROWSER_ADDITIONS_START -->

1. **手机页头挤压已修复。** 生产总览未声明共享页头依赖的容器，390 像素下标题曾被操作组挤成一字一行。手机回退布局将标题 / 操作分行，浏览器复验尺寸如上，不再以修复前截图作为交付证据。
2. **窄屏入口保留原视图。** `production-dashboard` 和 `rd-director-dashboard` 在窄屏继续原路由，避免自动改道后丢失新增风险 / 齐套能力；新增及更新移动路由行为用例 **10/10 通过**。这不意味着删除既有独立移动驾驶舱。
3. **开发模块加载恢复。** 既有 `/production-m` 曾因 Vite 内存优化信息指向已缺失的缓存文件而导入 `MobileRDCockpit` 失败。触发现有 watcher 重启后，静态依赖闭包 **115/115 返回 200**；主代理浏览器复查旧 `/production-m` 已正常。没有为此改写移动驾驶舱业务，详见[诊断与恢复证据](mobile-module-load-diagnosis.md)。该恢复属于本地开发服务，不是生产部署记录。
