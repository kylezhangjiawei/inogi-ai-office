# 管理首页入口与授权范围收尾

F02 风险服务已支持按真实采购、订单、质量及生产权限分别读取，本次补齐首页外层仍只允许生产管理人员进入的问题。

- 管理首页入口复用 `canReadManagementRisks`，采购驾驶舱、采购订单／订单详情、质量管理／复验等已有风险读取权限可以看到“管理总览”页签。仅关键物料权限、单独生产操作权限、仅本人生产作业页面权限不因此扩大为管理权限。
- 新增可见页签不改变采购和质量岗位原有“我的办公”默认首页；用户主动选择管理总览后通过 `home=management` 保留选择。既有生产管理和研发管理人员的默认页规则保留。
- 生产月度指标按原接口授权显示：研发总览权限，或生产执行页面并具有生产计划／全量查看权限。正式生产计划表仅在具有生产页面及全量管理权限时读取和展示。风险访问权限本身不会触发生产总览／计划请求，也不会出现未授权的零值、占位卡片或计划空状态。
- 风险区域保持各自真实业务范围；页面顶栏刷新会同时刷新风险面板。切月、权限收缩和退出管理范围立即隐藏旧生产数据并取消旧请求，晚到结果不能重新显示已经无权查看的区域。
- 本次仅修改 `managementDashboardModel.ts`、`managementDashboardApi.ts`、`ManagementDashboard.tsx` 和对应行为测试。`Dashboard.tsx` 沿既有模型挂载所选页签，无需增加第二套权限判断；没有扩大后端权限。

验证：管理首页、F02 风险、情景试算、个人原单及原首页定向回归 **27/27 通过**，前端 TypeScript 检查通过。日志 `management-home-access-tests.log`。未操作浏览器或写入真实业务数据。
