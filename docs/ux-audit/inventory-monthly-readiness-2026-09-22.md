# 库存齐套中心：月度计划融合

## 范围与实现

- 在原库存齐套中心内增加月度计划与齐套评估，不新增菜单或页面。
- 共用月份、产品型号和刷新入口。正式计划按月份与型号严格匹配，排除跨月结转；多个计划可选择。
- 展示计划、已完工、剩余需求和完工进度；整月/批次评估复用正式生产齐套接口及冻结 BOM，不复制计算公式。
- 日期内的预计齐套与原有“全部在途到齐后的库存能力”明确区分。缺依据显示待核对；下月没有正式计划显示未确认，请求失败显示暂不可用。
- 历史快照只读，可按原需求日期使用当前数据重新评估；保存另建快照，沿用来源标识、计划版本、操作原因及原权限校验。
- 核对入口复用生产齐套页，携带计划、批次、需求日期；不恢复此前删除的人员、任务列表及待下单采购情景。
- 未引入依赖、未改数据库结构、未扩大权限。新增英文文案同时进入内置兜底和服务端种子字典（未执行线上种子写入）。
