# 独立库存盘点：实现与验证

## 范围

- 仓库工作台新增“库存盘点”入口和按权限显示的“发起盘点”按钮。
- 独立页面 `/warehouse-count` 提供盘点列表、搜索、状态筛选、详情和操作记录；旧盘点链接转到此页。
- 发起只建立账面快照，仓库随后填写实盘，另一人复核后登记调整；原 ERP 库存不被直接覆盖。
- 当前复用既有单物料＋仓库汇总模型，不支持一张单多物料、库存批号级盘点或财务审批路由。盘点批次字段是范围说明，不是库存批号。
- 未修改实际角色授权，未向业务数据库提交测试盘点，未部署。

## 权限配置

| 用途 | 权限 |
| --- | --- |
| 查看独立盘点页 | `page:warehouse-count` 或既有 `page:warehouse-flow` |
| 发起盘点 | 页面权限＋`warehouse:count-initiate` |
| 提交实盘 | 页面权限＋`warehouse:count` |
| 独立复核 | 页面权限＋`warehouse:adjust`，不可复核自己填报的实盘 |
| 核对 ERP 凭证 | 页面权限＋`warehouse:reconcile` |

页面隐藏按钮与后端校验同时生效。未自动给任何真实角色增加新权限。
