# 布局与样式修复记录

日期：2026-09-18。对应 07-layout-style-health-2026-09-18.md。修改已在本地工作区完成，未提交或部署。

## 采用的视觉约定

Horizon 提供表面、层级和品牌语言，Linear 提供任务优先的信息组织。保留原有字体和配色：浅蓝白应用背景、白色工作面、深海军蓝正文、蓝灰辅助文字、紫色主交互。不添加渐变、插画或展示性统计模块。

共享尺寸由 theme.css 管理：侧栏 15rem（240px），页边距 1.5rem，控件圆角沿用 0.625rem，面板圆角沿用 1rem。采购页不再改变全局侧栏、导航项、顶部栏或主区域的尺寸。标题、数据、状态与操作保持独立层级；移动端压缩装饰性图标，保留真实 KPI 和业务字段。

## 审计项处理

| 审计项 | 处理结果 |
|---|---|
| 跨页框架漂移 | 侧栏改为共享变量，删除采购页对整个应用框架的特殊覆盖；三个抽查页面在 1440px 下侧栏均为 240px，顶部栏均约 73px。 |
| 任务入口过低 | 业务来源汇总与明细移至任务工作区后；窄屏常驻搜索与月份筛选入口，展开后保留月份、产品、供应商、状态四个字段；KPI 在窄屏压缩成一行。任务表起点从约 1115px 提前至 698px（390×844、全部进行中、主滚动位置为 0）。 |
| 嵌套滚动 | 移除采购任务表的固定高度、内部纵向滚动及滚动截断；移除详情面板和 ERP 订单记录的独立高度限制。桌面详情仍支持随页面粘附。任务分页与 ERP 分页保持原逻辑。 |
| 日志定位失效 | 公共 Collapsible、Trigger、Content 正确透传 ref；“操作记录”能展开、定位并聚焦日志。快捷菜单消失时，关闭抽屉可回到工作台当前任务详情。 |
| 提醒打断 | MateChat 提醒改为顶部非模态提示条，没有遮罩、自动焦点或背景滚动锁；保留账号隔离、时段、已使用判断、关闭与进入聊天入口。表单输入或模态操作期间延后检查提醒。 |
| 重复标题 | 当正文提供 h1 时，共享壳层保留当前位置并隐藏重复页标题；用户管理实测仅一个可见 h1。 |
| 样式覆盖债务 | 删除采购页对共享框架的覆盖及重复的滚动规则，控件和容器圆角改用现有 token。未对其他模块的历史 !important 规则进行全量删除；该项属于分段治理，本次完成所涉及范围。 |
