## 本轮实施范围

| 范围 | 页面与动作 |
| --- | --- |
| 接受报检 | 带入生产批次、工序、过程 / 终检、来源报工号、报检数量、日期和发布资料；由 QC 核对接收，未发布 SIP 阻断接收与检验 |
| 初检 | 填写实际初检量、合格量、不良量、证据和可选备注 / 照片，明确确认后保存；初检数量受本任务尚未检验范围限制，支持全合格记录 |
| 转不良处理 | 从具体原检验记录建立本页不良处理记录，保留原数量、现象、说明和人员；同一原不良范围不可重复转交。新记录尚无处置范围，不能立即复验 |
| 处置后复验 | 仅选择有处置单据、时间及可复验数量的范围；关联原检验、不良记录与处置依据，记录本次复验合格和不良。允许部分复验，未处置部分继续待处置 |
| 独立 QA 放行 | 仅 QA 可记录终检任务的授权放行；本轮要求该任务初检全部完成、不良全部解决后记录，分次放行不超过尚未放行量。保留授权依据、数量、人员、时间和说明 |
| 记录与来源 | 四个视图分别展示检验记录、不良与复验、QA 放行和操作历史；检验证据、照片、SIP 摘要和历史批次档案入口可核对。历史 SIP 必须匹配原记录的代码及版本，不能打开最新版本冒充原件 |
| 角色与恢复 | QC 可接收、检验、复验和转处理，QA 仅可独立放行，查看岗位与已关闭任务只读；保存失败保留输入，切换任务 / 人员 / 分类受未保存保护，旧上下文回调不得写入新任务 |

本页不修改不良处置结果或数量。处置记录由明确的演示依据提供，正式 P08 处置、责任分派、返工执行和消息发送留待后续接入。新转处理不等于真实质量人员已接单。

## 数量口径

1. **过程 / 终检与初检 / 复验是两个维度。** 按任务、工序和单位核对，不把过程检 160 件与终检 50 台相加，也不将检验次数作为整机完工。
2. **首次结果保持不变。** 一次合格率只取初检合格量除以初检量，未初检时显示无结果；复验合格不回填初检合格或冲减初检不良。
3. **复验从明确处置范围取量。** 本次可复验量为已确认可复验范围减去该范围已登记复验量。原不良量、已处置可复验量、尚待复验量分别显示；处置范围之外的不良不可借此复验。
4. **累计合格与未解决不良单独计算。** 首次合格加上已转为合格的复验范围形成累计合格，剩余仍不合格的实物留待进一步处置，不假装关闭原异常。没有实物或 SN 对应依据时，数量校验不能证明物理唯一；后续 P08 多轮处置须保留范围和原记录链，不能把每轮复验结果任意相加。
5. **QC 可发现现场自检未发现的问题。** P02 的自检不良是现场申报，不是 P03 检验上限。不得照搬正式台账“累计登记不良不得超过报工不良”的约束，使 QC 无法记录新发现的不良。
6. **检验、放行与出货分别保留。** 检验合格不自动创建 QA 放行，QA 放行不更新库存或出货。未检完、尚有未解决不良、无 QA 权限或超出可放行量时，本轮不允许记录放行。
