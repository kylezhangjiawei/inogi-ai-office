## 数据口径与约束

1. 整机完工、终检合格、质量授权放行及实际出货是四组独立证据。工序报工、重复复验或异常转交不能重复增加整机/不良数量；复验不能回填首次合格率。
2. 本批版本范围采用互斥分组表达已完工整机的历史实际版本，各范围数量合计不能超过已完工量。空缺数量或不完整软件/硬件/BOM 保留“待确认”；最新资料不能覆盖历史实际版本。
3. 范围可关联已有 SN；不能创造源中不存在的 SN，同一 SN 不能重复分配到不同范围。版本覆盖数量和 SN 覆盖数量分别计算，范围数量完整不代表逐台追溯完整。
4. 关键材料 SN 是材料序列号，整机 SN 是成品序列号，两者不可混用作整机已追溯数。没有逐台用料映射时只呈现批次关联，不从领料量反推逐台装配。
5. QA 放行必须有独立依据，检验通过不自动放行；已发货只说明有对应有效出货记录，不反向补造检验结果或授权人。
6. 来源记录及历史修订保留稳定 ID。每次演示修订保留前后快照、修改人、时间和原因，并检查当前状态版本。此检查不替代服务端权限、审计、事务或并发控制。
7. 批次档案中的原单查看为演示摘要。真实附件授权、文件完整性、受控发布状态、质量人员身份和现场原始证据留待接口阶段核验。
8. 独立内存模型只用于本次预览；刷新/重置恢复样例。不给正式 API、数据库、浏览器持久化、ERP 或仓管账写入。演示“只读”仅展示交互限制，不宣称正式角色授权已接通。
