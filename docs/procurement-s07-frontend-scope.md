# S07 采购人员任务阅读收尾

本轮在现有采购人员管理页增加每位人员的“查看全部任务”侧栏，读取原采购任务与成员名录，不增加业务写接口，不接入独立演示数据。

## 已补齐

- 每人可查全部已读取任务，包括完成、取消以及已移出名录人员的历史任务；人员负载与原交接操作仍只计算非终态任务。
- 按采购账号 ID 归属；没有 ID 的旧任务只在名录姓名唯一时回退匹配。同名歧义记录独立显示“历史姓名归属待核对”，同名账号显示账号标识。
- 需求月份、全部月份、普通采购/样品相关、进行中/已结束、任务/物料/供应商/订单搜索；每次展示 20 项，可继续展开。
- 跨月未完成、无需求日期未完成提醒独立计算，不受搜索、业务分类和列表状态筛选隐藏。点击提醒会清空上述筛选，打开该人员原任务。
- 当前节点和下一步复用既有采购状态口径；测试中的下一步需要当前轮次的有效样品依据。历史样品相关不等于当前待测试。
- 进入既有完整任务详情时只保留一个弹层；关闭详情返回原人员列表及原筛选，关闭人员侧栏恢复原入口焦点。完整详情中的原有操作继续使用既有权限。
- 任务或名录读取失败显示未知数量并可重试；账号、角色、部门或权限作用域变化时重新挂载页面内容，清空旧人员数据、选择和筛选。

## 数据边界

此处展示当前账号通过现有采购接口可见的任务。没有可靠个人数据源的仓管、质量任务明确未纳入；不显示假零，也不与生产/仓库独立演示数据合并。

月份只按合法需求日期归类，不使用创建日、Deadline 或预计到货日替代。无需求日期提醒包含格式非法的日期，列表显示待确认。样品归类基于原任务的要求、测试记录或免费样品关联，任务按原 ID 去重，不增加新任务。

现有名录、转派及完整详情的写操作未改业务契约；本轮验证只操作读取、筛选、展开、关闭等阅读行为，不写真实业务数据。

## 验证

`scripts/procurement-person-tasks.test.mjs` 的 12 项检查通过，覆盖同名账号、缺 ID 歧义历史、移出名录历史、重复快照、日期归月、独立提醒、样品分类、测试轮次、原任务详情、筛选恢复、来源失败和转派后详情失效；TypeScript 检查通过。

隔离真实组件在 390 × 844 浏览器通过复验：侧栏边界为 left 0 / right 390，内容没有水平溢出；完整详情关闭后保留“跨月未完成 + 进行中”筛选，焦点回到原任务按钮，页面仅保留一个对话框。侧栏采用显式视口宽度并关闭位移动画；标题焦点绑定原生 h2，不依赖未转发 ref 的包装组件。
