## 本批前端范围

| 范围 | 交互与结果 |
| --- | --- |
| 出货台账 | 客户、订单、产品和批次上下文；出库单号、实际出货日期、数量、经手人；搜索、状态筛选、选中详情及演示状态 |
| 分批登记 | 同一生产批次可有多条出货单；登记后为待确认；草稿尚未计入实际出货，修改保留原因与前后内容 |
| 实际出库确认 | 核对本次数量、生产批次、终检及放行依据后确认；只对有效确认记录计一次出货；重复确认、超可出货量、无效日期或来源不符应被阻止 |
| 冲销与更正 | 已确认的出货不直接覆盖数量、日期和批次；原因必填，原单保留；可建立关联原单的更正草稿；草稿再次确认前不增加出货量 |
| 已有 SN | 可补充已有 SN 并留痕；名单不能重复或多于本次数量；没有完整名单时显示待补齐，不能宣称逐台追溯完整 |
| 月度汇总 | 以实际出货日期归属月份，汇总已确认且未冲销的数量；目标为 0 时达成率显示“—”；完工、终检合格、授权放行和实际出货分别显示 |
| 关联批次档案 | 从本次出货查看演示批次、计划、产品、已知软件/硬件/BOM 版本及其适用数量、检验与放行依据、已有 SN、有效出货和冲销历史 |
| 通用保护 | 保存前确认、数量与日期校验、保存失败保留草稿、防重复提交、未保存切换提示、只读/空态/读取失败及恢复、响应式布局 |

动作类型为 `create`、`edit`、`confirm`、`reverse`、`sn`。经手人、质量依据、客户订单、单号和批次均为演示数据；显示文字依据不表示已上传文件、验证真实来源或完成正式授权。

P09 本轮服务于出货上下文查看，并非完整生产批次档案上线。当前类型以一个已知软件/硬件/BOM 组合及适用数量表达版本证据；未覆盖数量应显示待确认。完整的批内多版本范围、历史工序、领退料原单、原料批次、修订档案和全量 SN 追溯仍需后续数据建模与接口支持，不能自动用最新版填补历史。

## 数据与接口边界

- 使用本页独立的内存状态；刷新或重置演示恢复初始数据。草稿、出货、冲销和 SN 不写入浏览器持久化、数据库或真实业务系统。
- 开发预览路由及懒加载仅在开发环境启用；不修改正式菜单、权限、后端接口、数据库迁移或 ERP 同步任务。
- 每次确认只改变演示有效出货；冲销取消原记录的有效统计并保留历史。模型版本检查与状态限制用于前端交互评审，不能代替服务端事务、锁、权限、幂等或审计。
- 本轮与仓管、收货处置、质量异常等预览之间不共享库存、放行量或可发量；不把若干独立截图和样例拼成正式库存账。
- 整机完工、终检合格、审核放行、实际出货分别记账。A18 示例应保持完工 216 不变，有效出库增加 20 后使实际出货从 180 变为 200。
- 冲销表示台账记录作废/更正，不能自动等同客户实体退货或成品返库；客户退货的验收、质量状态和财务处理需另建业务流程。
- 原单据参考为演示文字证据。真实文件上传、下载授权、正式检验结论和授权人核验、外部订单状态、出库单唯一性与来源真实性均留待接口阶段。
