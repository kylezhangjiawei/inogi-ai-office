# S14 订单行履约台账（2026-09-14）

本轮补齐取消未交、退货、错误实收冲销、ERP 覆盖确认，以及批准后净履约量、检验可用量和受影响备货计划重算。订单详情的原 ERP 数量保留；新「履约调整与可用量」入口提供登记、审批、撤销及完整记录。同页另接入独立「供应商承诺与交期历史」入口，并支持返回原到货排期。

## 数量口径

- ERP 累计到货与本地逐笔收货分别展示，任何汇总都不把二者相加。
- 取消只减少尚未交付的订购义务。取消上限同时受 ERP 未收量和本地已登记净实收约束。
- 退货保留补交义务；冲销用于纠正错误实收。二者都引用明确收货 ID 和合格、不良、待判、待检中的一个数量桶，不按 SKU 合并、不覆盖原收货。
- 待确认事项不影响数量。只有已批准且未撤销的事项参与计算；撤销同样留原因、操作人和时间。
- ERP 覆盖确认须证明「本地净实收 = ERP 累计到货 - 尚未在 ERP 反映的批准退货/冲销」。确认时逐条指定哪些调整已在当前 ERP 数量中反映，避免 ERP 后续同步后再扣一次。
- 覆盖锚定订单来源及数量、全部收货 ID/检验版本、当前批准数量调整集合。任一变化即失效。已在 ERP 反映的调整被撤销时，净履约量也回到待核对，不假装 ERP 被同步撤销。
- 检验可用量只在完整覆盖成立时提供，取本地最新累计判定减去批准扣减后的合格净量；它不代表仓库可领库存，也不写入 ERP 库存。
- 单位不一致、重复订单行关联、来源变化、判定桶为负等异常返回 `null` 和原因，不以零替代未知量。逐行未收独立求和，超收不能抵扣另一行未收。

## 持久化和权限

使用既有 `RuntimeState`，键为 `procurement:fulfillment:v1:<mirrorId>`，无需新增表或改变 ERP 同步表。事务先锁 `ProcPurchaseOrderMirror` 订单行，再校验来源更新时间与台账版本；审批和收货、检验共用该订单行锁。台账和 `AuditLog` 同事务写入，审计失败即回滚。

每次操作携带 requestId；同一操作人、同一内容的重试返回现状，不追加历史。不同内容复用同一 ID、旧版本和旧来源均被拒绝。

- 读取：`page:purchase-order-detail`。
- 登记和撤销待确认记录：页面权限加 `proc-purchase-order:adjust-fulfillment`。
- 批准：页面权限加 `proc-purchase-order:approve-fulfillment`。
- 撤销已批准记录还要求审批权限。
- 关联备货计划仅向具有 `page:proc-cockpit` 的账号返回；无权限时明确显示不可查看，不误报为未关联。

前端按订单行、账号和权限集合隔离会话。范围切换清空旧草稿并忽略迟到读取/保存；保存期间锁定关闭。普通关闭遇到未保存的调整或审核依据时要求确认丢弃，继续填写会保留内容。

HTTP 入口：`/api/procurement/purchase-order-lines/:lineId/fulfillment`；POST 登记，`/:entryId/approve` 批准，`/:entryId/revoke` 撤销。所有操作都要求原因，ERP 始终只读。本轮没有发送站内通知或写实际业务库。

## 收货、检验和计划联动

收货上限改为本地净实收不得超过净订购量，因此批准退货/冲销并核对覆盖后可登记补交；原始收货累计仍完整保留。检验修订不能减少到低于已批准退货/冲销所引用的判定桶，避免已经移出的数量再次变成可用。

备货计划 list、详情、齐套读取新增 `fulfillmentSummary`。计划面板保留明确标注的 ERP/历史原值，并展示实时重算的仍需采购、仍需到货和检验可用数量。手工批次没有明确 ERP 订单行身份时，不与 ERP 供给合并；独立无单号手工采购保留原采购/实收口径，但没有逐笔检验证据则不提供检验可用量。ERP 已作废订单不抵扣后续采购需求。

重算按计划当前物料映射检查 ERP 物料编码；同一镜像 ID 后续换料不会继续抵扣旧计划。每个收货批次单列 `issues`，ERP 关单或其他批次异常不会抹掉该批次有证据的待检数量。

`readPurchaseFulfillment` 和 `calculatePurchaseFulfillment` 可供仓管、质量待办复用。真实收货的 `createdById/createdByName` 是登记人，检验同字段是判定人，并非任务负责人；分派由独立任务表/台账维护。

ERP 量产仓库存余额不与本地合格量相加。发生本地批准调整时，现有 ERP 库存/在途核算标记为暂估；不能用本地台账擅自修改 ERP 库存。整机订单净采购量尚未核对时，阻止据此自动拆分采购任务。
