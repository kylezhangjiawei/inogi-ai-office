## 数据口径

测试详情目前只有一份 `sampleTest` 记录。`assignedAt` 是分派操作时间，`confirmedAt` 是结论提交时间；它们不能代表实际到样、开测或测试结束。页面没有生成不存在的时间或完整轮次历史。

任务预计到货来自 `expectedArrivalDate`，不保证是当前样品轮次的承诺日期。实际到样日期显示“未记录”；缺失的测试起止时间在说明中明确。失败重送、重新询价或回退后的旧测试记录保留其原始操作时间，并说明不能据此确认本轮已到样。

采购条件来自原任务已选报价，不是本轮样品成交结果。只依赖精确任务关联，不按物料名称混配；没有正式任务物料 ID 时仍保留原任务的合法多条报价，并标明物料待核对。报价物料 ID 与已知任务物料 ID 冲突时也显式提示。单位、税费、付款、运输及交期起算日缺少独立结构化依据，不推算合价或承诺到货日期。
