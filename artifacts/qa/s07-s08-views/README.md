## 复现

在仓库根目录运行：

```sh
node artifacts/qa/s07-s08-views/harness/server.mjs
```

打开 `http://127.0.0.1:4182/__qa/s07-s08`。需要端口 4182 可用。原先4181采购收尾预览不受影响。

- **采购工作台** → 展开“到货安排” → “到货日历”：20行完整关联，9月18行、日期待确认2行。选9月13日（13行），下一页打开订单第8行，再点“返回采购工作台”，验证日期、页码和原行焦点。
- **人员任务**：两个同名采购账号分别11项与1项，缺ID的同名历史单列，另有只含已完成记录的非名录人员。进入每人全部任务，搜索无匹配后独立提醒仍可用；从跨月任务进入完整详情，再关闭，筛选与按钮焦点保留。
- **历史报价**：正式物料ID只读30/32元两条，均价31；同名候选额外包括另一规格1元，但不显示最低、均价与趋势。
- **模拟失败 tasks**：团队和人员计数显示未知而非0；恢复后重新计算。其余顶部按钮沿用上一阶段的订单历史、计划读取和权限样例。
