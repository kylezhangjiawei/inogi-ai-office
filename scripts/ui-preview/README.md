# 独立采购 UI 验收沙箱

启动（项目根目录）：

```sh
node node_modules/vite/bin/vite.js --config scripts/ui-preview/vite.config.ts
```

打开 http://127.0.0.1:5175 。仅监听本机，端口占用时直接退出。

- 复用真实报价库、人员管理、个人工作台、成员抽屉、历史价格与导入核对展示组件。没有复制生产页面实现。
- 数据完全由 `fixtures.ts` 构造：63 条物料、16 个虚构人员、48 个采购任务、27 条历史报价、43 条导入核对记录。包括重名人员、停用账号、长名称、多币种、多个阶梯价与不同状态。
- 独立 Vite 配置只替换本沙箱加载的 `src/app/auth` 模块，返回虚构展示账号；生产登录、权限实现、API 客户端、入口与路由均未改动。没有登录令牌。
- `/api/` 的 GET 请求仅返回本地合成 fixture；未知接口返回 404。除下述白名单内存模拟 POST 外，所有非 GET/HEAD 请求直接返回 405；没有 API 代理、数据库连接或业务写入能力。开发页还限制连接只到自身来源。
- 语言切换复用现有 i18n 方法，只更新此独立来源的本地偏好；其服务端偏好写请求同样被 405 拒绝。英文采用项目内置 fallback 字典，动态业务文字不调用真实翻译服务。
- 主导航用于直接切换验收页面。“抽屉与历史”还提供 3 条补货建议、批量转派、新建需求及编辑任务表单。控件可展开、搜索、翻页、排序与打开弹窗，提交类控件只会收到沙箱禁写提示。
- 沙箱不加载生产桌面导航与移动路由守卫，可缩窄窗口检查组件本身；这不代表生产采购路由已支持小于 768px 的设备。

闭环验收新增真实订单工作台与齐套组件。模拟 POST 白名单仅为 `PREVIEW-ORDER/preview-line` 的物料关联，以及 `previewScenario=bom-flow` 下 `preview-device` 的绑定/发布和 `preview-revision` 停用。只修改进程内虚构变量，重启即丢失；其余写入仍全部 405。不模拟数据库约束，不代表真实联调通过。`?previewScenario=reader|conflict|zero|stale|unknown|bom-flow` 用于角色、冲突、零库存、失效、缺同步和 BOM 流程（一次一个值）。页面说明的“禁止业务写入”不限制该内存模拟。

仓库工作台新增只读验收入口 `/warehouse-flow`：两条虚构派工与对应待接收退料，用于检查派工关联、退料切换及窄屏布局；不开放发料、签收或退料写入。报价库目录/供货资格接口尚无沙箱夹具，相关错误提示属于沙箱覆盖限制，不能作为真实接口异常的结论。

这是验证生产组件布局的开发工具，不是新的应用入口，不随生产构建发布。请在结束验收后停止该独立进程。
