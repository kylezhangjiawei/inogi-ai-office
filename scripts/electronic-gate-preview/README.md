# 电子闸门交互预览

此宿主直接复用生产 `ElectronicGatePage`、读取协议及连接参数状态组件，注入独立示例 API。侧栏与面包屑用于还原页面，其他模块不在此预览范围。

从仓库根目录启动：

```powershell
node node_modules/vite/bin/vite.js --config scripts/electronic-gate-preview/vite.config.ts
```

打开 `http://127.0.0.1:5184/`。固定使用此本地端口，端口被占用时退出，不改用其他端口。Vite 不读取任何 `.env`，没有后端代理，所有 `/api/` 请求和写入 HTTP 请求都被拒绝；响应头 `X-Electronic-Gate-Preview: local-synthetic-data` 标明隔离预览。

## 本地示例状态

检测项直接复用后端纯目录常量，初始没有任何已发布规则。第 16 项包含未发布的示例草稿，其参考值不代表产线标准。保存和发布只写入预览 origin 的 localStorage，存储键为 `inogi.electronic-gate.interactive-preview.v1`。如需重置，从浏览器站点设置中清除此站点的测试数据。

支持逐项草稿、逐项发布、草稿与生效值分离、重载持久化及基于 revision 的乐观并发冲突。两窗口并行修改同一项可检查冲突提示；浏览器 Web Locks 可用时保证写入串行校验。新增草稿不会覆盖上一版已发布值，发布后清除该项草稿。

## 当前读取协议

没有草稿和已发布目录时，页面只读展示 `factory-qc.defaults.ts` 中的当前默认目录 `builtin-20260909-v3`，与 Windows 客户端 v0.5.0 默认协议一致。默认先显示 `v4-20260908`：22 项定义中启用 20 项，73、78 停用；79 使用两字节大端有符号整数温度；83 的后两字节保留为 HEX 原始字节。7D 的字节序、单位等待核实事项在展开说明中保留，构造样本不等于实机证据或质量标准。

预览不会执行生产服务的启动初始化。初始显示“默认参考 · 尚未初始化”“尚未发布 · 暂不可下载”是正常状态。页面中的两个地址是用户确认的生产客户端下载目标：

- `https://www.weoxymedical.com/api/factory-qc/serial`
- `https://www.weoxymedical.com/api/factory-qc/protocol`

复制按钮只复制地址，不请求这些接口。预览中的“已发布”和版本号仅代表当前预览的本地状态，不证明真实域名已部署，也不表示 Windows 工位已经下载。

首版演示流程：载入 v0.5.0 默认配置 → 校验目录 → 保存目录草稿 → 核对字段与样本 → 发布完整目录。载入只改变本地编辑器，保存不会发布；首版必须完整发布。已有首版后，可逐项保存并发布；“载入 v0.5.0 本项默认”经确认后只替换该项本地输入（包括字段、样本和自定义枚举），仍需检查、保存及发布。

完整目录的版本号对应不可变快照。如果此版本已在历史中存在，修改后发布需使用新的版本号；恢复旧内容请走历史回滚。默认模板不会静默覆盖已有内容。

## 历史资料

原 v2 示例 `builtin-20260909-v2` 保持原样，可在完整目录导入区载入作为历史格式参考。原 r5 研发回复保留在单项展开区域的折叠历史说明中；它的 78、83 和断电流程描述已经由当前 v0.5.0 说明更新，不再作为主要建议。

预览仍复用 `factory-qc.release.ts` 的来源检查：r4 历史候选 `candidate-20260909-v3` 与 r5 审核模板 `review-r5-20260909` 的原版本号、原内容，以及仅修改版本号的同内容，均不能直接发布或回滚为生效版本，可以保存为待修订草稿。结构、样本和来源检查通过不证明目标固件已修正、测量有效或质检合格。

## 串口状态与隔离边界

协议管理及历史另存于 `inogi.factory-qc.interactive-preview.v1`，与连接参数共用浏览器写锁。预览的串口快照必须由 12 项实际发布配置生成，11 项时不会用默认值补齐；它不会自动运行生产数据库的默认值初始化。历史回滚恢复通过来源检查的原版本号和原 JSON，保留其他草稿。

所有保存、发布和回滚都只作用于预览站点的 localStorage，不部署或发布真实配置，不验证真实数据库、HTTPS 入口或串口设备。生产服务的幂等初始化策略应以实际服务代码及上线文档为准。

访问 `http://127.0.0.1:5184/?scenario=load-error` 检查加载失败状态。去掉查询参数恢复正常预览。
